## Usage

```tsx
import { BoardCard } from "@/components/ui/board-card"
```

```tsx
<BoardCard itemId={task.id}>
  <span className="font-medium">{task.title}</span>
</BoardCard>
```

`itemId` is written to the HTML5 drag payload (`dataTransfer.setData("text/plain", itemId)`)
on drag start — a [`BoardColumn`](/docs/components/board-column) reads it back
in its drop handler. Everything else is a plain `<div>`: pass any children,
`className`, or other div props and they render inside the card shell.

## API Reference

| Prop     | Type     | Default | Description                                                            |
| -------- | -------- | ------- | ---------------------------------------------------------------------- |
| `itemId` | `string` | -       | Written to the drag payload on drag start; read back by `BoardColumn`. |

Extends `React.ComponentProps<"div">` — every native div prop (`className`,
`children`, `onClick`, …) is forwarded.
