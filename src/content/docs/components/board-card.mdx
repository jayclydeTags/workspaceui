## Usage

```tsx
import { DndContext } from "@dnd-kit/core"

import { BoardCard } from "@/components/ui/board-card"
```

```tsx
<DndContext onDragEnd={handleDragEnd}>
  <BoardCard itemId={task.id}>
    <span className="font-medium">{task.title}</span>
  </BoardCard>
</DndContext>
```

`itemId` is passed to dnd-kit's `useDraggable({ id: itemId })` — the board's
`DndContext.onDragEnd` reads it back off `event.active.id` (see
[`BoardColumn`](/docs/components/board-column) for the full move-on-drop
wiring). A `BoardCard` needs a `DndContext` ancestor to actually be
draggable; render one per board, wrapping every column. Everything else is
a plain `<div>`:
pass any children, `className`, or other div props and they render inside
the card shell. Because dragging comes from dnd-kit, cards are draggable by
keyboard too — `Tab` to focus a card, `Space` to pick it up, arrow keys to
move it between columns, `Space` again to drop.

## API Reference

| Prop     | Type     | Default | Description                                                            |
| -------- | -------- | ------- | ---------------------------------------------------------------------- |
| `itemId` | `string` | -       | Written to the drag payload on drag start; read back by `BoardColumn`. |

Extends `React.ComponentProps<"div">` — every native div prop (`className`,
`children`, `onClick`, …) is forwarded.
