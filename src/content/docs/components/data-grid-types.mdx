`data-grid-types` has no component and no visual output — it's the shared
`column.meta` type contract that `data-grid` (and, later, `data-filter`) build
on. Both list it as a `registryDependencies` entry and install it
automatically.

## Usage

Nothing to import — the file's only job is a side-effecting `declare module
"@tanstack/react-table"` augmentation of `ColumnMeta`. Once it's part of your
TypeScript program (installing the file is enough), every `columnDef.meta`
you write is typed against it:

```tsx
const columns: ColumnDef<Contact>[] = [
  { accessorKey: "name", header: "Name", meta: { type: "text" } },
  {
    accessorKey: "status",
    header: "Status",
    meta: {
      type: "select",
      options: [
        { value: "open", label: "Open" },
        { value: "closed", label: "Closed" },
      ],
    },
  },
]
```

## Column types

Eight types are declared now so `data-grid` and `data-filter` never have to
re-open the contract. Only **`text`** has a working cell editor today (see
[Data Grid](/docs/components/data-grid)) — the rest exist so you can type your
columns now and get the editor for free once a later component ships it.

- `text`, `number`, `currency`, `select`, `boolean`, `date`, `multiSelect`, `user`
