## Usage

```tsx
import { SecretField } from "@/components/ui/secret-field"
```

```tsx
<Field>
  <FieldLabel htmlFor="secret-key">Secret key</FieldLabel>
  <SecretField id="secret-key" value={apiKey} />
</Field>
```

While masked, the input only ever holds the masked string, so selecting and
copying the text by hand can't leak the secret. The copy button always writes
the full value, and a polite status message confirms it for screen readers.

## API Reference

Extends `React.ComponentProps<"input">`, minus `value`, `defaultValue`, `type`,
`readOnly`, and `onChange`. Other native props (`id`, `aria-label`,
`disabled`, …) go to the underlying input.

| Prop           | Type                      | Default | Description                                                                 |
| -------------- | ------------------------- | ------- | --------------------------------------------------------------------------- |
| `value`        | `string`                  | -       | The full secret. Only ever written to the clipboard or shown when revealed. |
| `revealable`   | `boolean`                 | `true`  | Show the reveal toggle. Set `false` for secrets that must stay masked.      |
| `visibleChars` | `number`                  | `4`     | Trailing characters left visible while masked. Capped at half the secret.   |
| `onCopied`     | `(value: string) => void` | -       | Called after the secret is written to the clipboard, e.g. to show a toast.  |
| `className`    | `string`                  | -       | Additional CSS classes applied to the input.                                |

## `maskSecret`

The masking function is exported for use in tables and lists of keys:

```tsx
import { maskSecret } from "@/components/ui/secret-field"

maskSecret("sk_demo_51HxQ2mZ9aB3cD4eF5gH6iJ7k") // "sk_demo_•••…iJ7k"
```

A leading `word_` or `word_word_` prefix is kept intact, the dot run is capped
at 24 characters, and no more than half of the secret body is ever shown.
